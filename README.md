# Screen Translator 2.0

![Version](https://img.shields.io/badge/version-2.0-75B8FF)
![Platform](https://img.shields.io/badge/platform-Windows%2010%20%2F%2011-blue)

Экранный переводчик для Windows x64: выделите область экрана и получите перевод рядом с ней.

## Скачать

Откройте [Releases](../../releases). Доступны два варианта одного приложения:

| Lite | Full |
|---|---|
| `ScreenTranslator-Lite.exe` | `ScreenTranslator-Full.exe` |
| Встроенный OCR Windows | OCR Windows + встроенный Tesseract 5.5.3 |
| Маленький размер | Больше размер, автономные модели OCR |
| Нужны подходящие языковые компоненты Windows | 24 встроенных языка не требуют установки OCR Windows |

В обеих сборках: компактное окно, круговая загрузка, 109 языков перевода в списке, поиск на русском, история последних 50 переводов в рамках запуска, перевод буфера обмена, горячие клавиши. Python для готового EXE не нужен. Перевод требует интернета, OCR выполняется локально. Доступность переводов зависит от внешнего сервиса.

### Встроенные языки Full (OCR)

Русский, английский, арабский, немецкий, французский, испанский, итальянский, португальский, турецкий, украинский, белорусский, казахский, азербайджанский, хинди, китайский (упрощённый и традиционный), японский, корейский, персидский, иврит, польский, нидерландский, чешский, вьетнамский.

Для надежного распознавания текста не на русском и не на английском выберите язык оригинала вручную в настройках. Автоматическое определение при работе резервного Tesseract использует русский и английский. Остальные языки из списка могут работать через OCR Windows или отдельные языковые компоненты. Это не офлайн-переводчик.

## Использование

1. Запустите EXE. Значок появится около часов.
2. Нажмите **Ctrl + Alt + T** и выделите область с текстом.
3. В появившемся окне можно скопировать перевод, выбрать другой язык или закрепить результат.
4. Esc закрывает окно, правый щелчок по значку открывает настройки.

Закройте предыдущую копию перед запуском новой: обе сборки используют одинаковые настройки и горячие клавиши. Если включена автозагрузка, выключите и включите её снова из новой версии для обновления пути к EXE.

## Сборка на ПК

Нужен Windows x64 и 64-битный Python 3.12 с Tkinter. Для Full также нужен [7-Zip](https://www.7-zip.org/). Скачайте и распакуйте проект, запустите:

- `build_lite.bat` или `build.bat` — Lite;
- `build_full.bat` — Full.

Скрипт создаст окружение, установит PyInstaller и соберёт файл в `dist/`. Для Full скачивает официальный установщик Tesseract, сверяет SHA-256, извлекает OCR без установки и скачивает 24 модели из релиза tessdata_fast 4.1.0. Проверяет загрузку каждой модели и наличие встроенного OCR в готовом EXE. Повторная сборка использует проверенный локальный кеш `tesseract/`. Результат не содержит установщика. Сборка требует доступа к GitHub и PyPI.

## GitHub Actions

Загрузите файлы в корень существующего репозитория, включая `.github/workflows/build.yml`. Если папка не загрузилась в браузере, создайте файл по этому пути вручную. Старые `translator.pyw` и `gitignore` можно удалить из основной ветки после проверки; старый релиз 1.9 сохраняется. `build_full.bat` заменяется новым файлом.

Откройте **Actions → Build Windows EXE** и выберите запуск для последнего коммита. Сборка также стартует автоматически при push в main или master. Ожидайте зеленых отметок обоих заданий Lite и Full. Скачайте соответствующие артефакты и распакуйте ZIP с EXE.

Если тег `v2.0` еще не существует, создайте его на новом коммите, чтобы автоматически опубликовать обе сборки. Если релиз v2.0 уже опубликован, не переносите старый тег: можно вручную добавить новые EXE к нему (с указанием, что это обновленная сборка) или создать новый тег `v2.0-full` на текущем коммите. Workflow публикует файлы при push тега `v*`, если разрешены соответствующие права Actions.

## Конфиденциальность и диагностика

Изображения распознаются локально, распознанный текст отправляется Google Translate / MyMemory. Не отправляйте конфиденциальные тексты. Настройки: `%APPDATA%/ScreenTranslator/settings.json`. Журнал: `%TEMP%/ScreenTranslator.log`. EXE не подписан цифровой подписью. Защищенные окна и эксклюзивный полноэкранный режим могут не захватываться.

Перед публичным распространением Full ознакомьтесь с `THIRD_PARTY_NOTICES.md` и лицензиями всех фактически включенных библиотек. Лицензию самого приложения выбирает владелец проекта.
