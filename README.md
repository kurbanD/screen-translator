# Экранный переводчик

Выдели область на экране — программа распознает текст и переведёт его: русский → английский, всё остальное → русский. Работает в играх (в режиме «Окно без рамки»), видео, картинках, PDF — везде, где текст нельзя выделить мышкой.

Для Windows 10 и 11.

## Как пользоваться

1. Запусти программу — в трее (у часов) появится значок.
2. Нажми **Ctrl+Alt+T** — экран замрёт и затемнится.
3. Обведи мышкой нужный текст.
4. Рядом появится перевод. Esc — отмена, кнопка «Копировать» — скопировать перевод.

Правый клик по значку в трее → **Настройки**: сочетание клавиш, язык перевода, затемнение, размер текста, автозапуск.

## Скачать

Готовая программа — на странице [Releases](../../releases): **ScreenTranslator-Full.exe**.

Распознавание текста встроено, ничего устанавливать не нужно (ни Python, ни языки Windows).

Windows может показать предупреждение «Windows защитила ваш компьютер» (файл не подписан): нажми «Подробнее» → «Выполнить в любом случае». Антивирус при необходимости добавь в исключения.

## Сборка из исходников

Нужен Python 3 и интернет. Положи `translator.pyw` и `build_full.bat` в одну папку и запусти `build_full.bat` — он сам поставит Tesseract, скачает языки и соберёт `dist\ScreenTranslator-Full.exe`.

Или запусти без сборки: `pythonw translator.pyw`.

## Если что-то не работает

- **«Слишком много запросов»** — бесплатные сервисы перевода временно ограничили запросы, подожди пару минут.
- **Затемнение не видно в игре** — переведи игру в режим «Окно без рамки».
- Ошибки пишутся в файл `%TEMP%\ScreenTranslator.log`.

## Приватность

Распознавание текста идёт на твоём компьютере. В интернет уходит только распознанный текст — для перевода (Google Translate, при ограничениях — MyMemory).
