# История версий

## 2.0

- Компактный интерфейс и круговая анимация загрузки.
- Расширенный список языков на русском с поиском.
- Выбор направления перевода в окне результата, перевод буфера обмена.
- История, закрепление, копирование оригинала и результата.
- Автоматическая сборка EXE для Windows и публикация через GitHub Actions.

Номер 2.0 присвоен существующей доработанной версии переводчика (ранее 3.1).

### Два варианта сборки 2.0

- Lite: системный OCR Windows, без встроенного Tesseract.
- Full: Tesseract 5.5.3, 24 языковые модели tessdata_fast, резервное локальное распознавание.
- Раздельные EXE, автоматическая проверка обеих сборок и публикация двух файлов.
